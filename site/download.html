Installation

You can easily install boredOS on a USB drive using utilities such as: dd, Ventoy, or Rufus. After installing the .iso file to a USB drive, you can boot from it. Via your BIOS / UEFI. Once booted into BoredOS, use boredos-install to install BoredOS to your hard drive.

Running in QEMU

You can use QEMU to test out BoredOS and see if you want to install it or not. You can do this using the Makefile run-YOUROS scripts.
