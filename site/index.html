An operating system made out of infinite boredom.

BoredOS is a from-scratch x86-64 UNIX-like operating system written mostly in C. It includes a custom windowed desktop environment (Nova), a package manager (bpm), and an expanding set of ported software.

Automated nightly builds are freely available on our download page.

BoredOS is developed and maintained by volunteers in their spare time and has no corporate backing.

You can explore the source code and documentation on GitHub and join the community on Discord or Matrix.
