BoredOS Building from Source

BoredOS can be built on Unix-like host environments using the official BoredOS cross-toolchain and standard build tools.

Requirements

Package / Tool
BoredOS Toolchain
GNU Make (make)
NASM (nasm)
Host C Compiler (gcc or clang)
Git (git)
cURL (curl)
Meson (meson)
Ninja (ninja-build)
Python 3 (python3)
LZ4 (lz4)
Tar (tar)
xorriso (xorriso)
Bash & standard POSIX utilities
QEMU (qemu-system-x86_64, qemu-img)
OVMF / EDK2 (optional, for UEFI)

Getting the Source

git clone https://github.com/BoredOS/BoredOS.git
cd BoredOS

Toolchain Setup

Download and extract the latest prebuilt cross-compiler from the BoredOS Toolchain releases.

Building the System

# Clean up any artifacts
make clean

# Compile kernel, userland, and build boredos.iso
make -j4

Running in QEMU

# Run the live ISO image
make run -j4
